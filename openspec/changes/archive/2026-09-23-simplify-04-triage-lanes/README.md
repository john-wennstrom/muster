# simplify-04-triage-lanes

Part 4 of 7 in the harness simplification series (see `docs/simplification.md`). Adds the lane concept (small, medium, large) and one merged Jev triage decision that runs before any agent and chooses the lane, replacing the preflight and complexity decisions. Lanes are recorded and shown; small and medium start to differ in behavior in simplify-05 and simplify-06. Depends on simplify-03-judgment-core.
